## Metrics Tracked

### Weighted-CRAP (wCRAP)

Combines cyclomatic and cognitive complexity with test coverage to identify high-risk methods:

```
W = sqrt(cyclomatic × cognitive)
wCRAP = W² × (1 − coverageFraction)³ + W
```

- **wCRAP < 6:** Low risk
- **wCRAP 6–30:** Moderate risk; review for testability
- **wCRAP > 30:** High risk; refactor or add tests
- **wCRAP > 100:** Critical risk; brittle and unmaintainable

### Thresholds

- **Worst-15% cutoff:** wCRAP ≥ 6.00 (492 methods as of September 2026)
- **High-risk threshold:** wCRAP > 30 (139 methods)
- **Critical threshold:** wCRAP > 100 (specific count TBD in detailed reports)

## Tooling

**Analyzer:** [SlopGuard-Swift](https://github.com/example/slopguard-swift) 0.1.0  
**Upstream commit:** `70245e434a271d6ce95a62976d67f7a14f9f298c`

SlopGuard analyzes Xcode `.xcresult` bundles to compute wCRAP scores per method. Output includes JSON, HTML reports, and method-level hotspot rankings.

## Workflow

1. **Establish baseline:** Run full test suite with coverage; analyze with SlopGuard; commit Markdown summary (not raw output)
2. **Create child issues:** Break worst-15% hotspots into scoped issues with behavioral goals and verification scope
3. **Refactor incrementally:** One logical change per PR; preserve tests; measure wCRAP reduction
4. **Re-baseline periodically:** Track progress as coverage and complexity improve

## Build Artifacts

The `build/slopguard/` directory (in `.gitignore`) contains large JSON/HTML reports generated by SlopGuard. **Do not commit** these artifacts. Commit only derived Markdown documentation like the baseline and child-issue specs.
