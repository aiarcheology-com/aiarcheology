Test Focus: Web-snapshot rendering refactor (AIA-0389) — no visible change expected
Build: TBD

What's new in this build:
The code that captures a snapshot of the web page (the frames detection runs on, and the
image a saved finding keeps) was moved onto a new internal renderer. There is NO intended
change to what you see — this build is a regression check that everything the snapshot feeds
still works exactly as before.

1. Detection still works (boxes)
- Run a detection demo and browse: bounding boxes should appear over recognized content and
  clear when it leaves the screen, just as before. Scroll/rotate and let it settle — boxes
  should re-appear, with no lag, freeze, or stale boxes.

2. Image adjustments still apply
- Open the snap adjustment controls and change Brightness / Contrast / Saturation. The
  detection snapshot (and what the models see) should reflect the adjustment as before —
  the sliders must still visibly affect the result.

3. Save a finding (manual pick)
- Enter finding-capture / pick mode and save a finding: the captured image must be the exact
  frame you picked, and the saved finding should look correct. This path was rewired, so
  please exercise it a few times (including cancelling a pick).

4. Classification finding-flash still works
- With a classification model enabled, the pulsing frame flash and label bubble should still
  appear on recognized content (unchanged).

5. Report Issues
Please report any issues with:
  * What you were doing (steps to reproduce)
  * Device model and iOS version
  * Screenshot or screen recording if possible
