Test Focus: Extended model catalog — browse and download convertible ONNX models with an honest support badge, and filter by task and model family.

What's new:

• The catalog now lists on-device-convertible ONNX models (not only Core ML), including SqueezeNet, each with an honest badge: Verified, Generic Labels, or Convertible.
• New filter chips — Task (Classification / Detection) and Model (MobileNetV2 / ResNet-50 / SqueezeNet / YOLO / Other) — that combine with AND and compose with the source filter and search.
• With a filter selected and no search text, curated sources now browse their full list.

Please test:

1. Open the catalog, tap the Detection task chip with no search text, and confirm you can browse detection models across sources without typing anything.
2. Add the YOLO model filter on top of Detection; confirm only YOLO detectors remain, then tap Clear Filters and confirm the full list returns.
3. Download and open the curated SqueezeNet (ONNX) entry; confirm it downloads, converts on-device, and imports as a working classifier.

6. Confirm a model tagged "ONNX" is never also labelled "Core ML", and a search result whose format is not yet known shows no format tag at all.
