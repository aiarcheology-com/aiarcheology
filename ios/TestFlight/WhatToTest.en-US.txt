Test Focus: Groundwork for modern YOLO detectors — existing conversions must not change

What's new:

• Internal converter groundwork for modern YOLO detectors (YOLOv8/YOLO11). Nothing new is user-visible yet — detection boxes for these models arrive in the next build. What matters in THIS build is that everything that already worked still works exactly the same.

Please test:

1. Import an image classifier by URL (e.g. MobileNetV2, ResNet-50, or SqueezeNet from the ONNX Model Zoo) — it must convert and classify page images as before.
2. Import Tiny YOLOv2: https://github.com/onnx/models/raw/main/validated/vision/object_detection_segmentation/tiny-yolov2/model/tinyyolov2-8.onnx — detection boxes with labels must still appear over photos, unchanged from the previous build.
3. New behavior worth a look: importing a modern YOLO file (e.g. a yolov8n.onnx export) no longer fails with an "unsupported operator" error — it imports successfully but appears in the model list as Disabled / needing review, and cannot produce detections yet. That is expected in this build.
4. Detection models with embedded post-processing (SSD, tiny-yolov3) should still be rejected with a clear message.

Known limitations:

• Modern YOLO (v8/v11) files convert but do not yet detect — the detector wiring ships in the next build. Only YOLOv2-family detection models produce boxes today.
