Test Focus: UI Responsiveness during Model Import
Build: TBD

This build improves UI responsiveness by moving heavy operations (model loading, file copying) off the main thread. The app should feel smoother, especially during model import.

Devices / Platforms
- iPhone (required)
- iPad (if available)

1. Model Import (Primary Focus)
- Import a model from Files (Settings → Add Model → Import from Files)
  * The "Validating model..." spinner should animate smoothly
  * The UI should NOT freeze or stutter during import
  * Try importing larger models if available (.mlpackage files)
- Download a model from URL
  * Same expectations: smooth animation, no freezing

2. First Launch Experience
- Delete and reinstall the app (or reset via Settings)
- On first launch, demo models are loaded automatically
  * The app should remain responsive during this process
  * No visible lag or frozen UI

3. Core Regression
- Browse websites and confirm web view loads normally
- Run object detection and verify annotations appear correctly
- Switch models/configurations and verify detection works
- Delete a model configuration and confirm it's removed cleanly

4. Settings & About
- Open Settings → About → tap the email contact button
  * Device info should load without freezing the UI
- Clear browsing data (Settings → Clear Cache)
  * Should complete quickly without UI stutter

5. Report Issues
Please report any UI freezes or stutters with:
  * What you were doing (steps to reproduce)
  * How long the freeze lasted
  * Device model and iOS version
  * Screenshot or screen recording if possible
