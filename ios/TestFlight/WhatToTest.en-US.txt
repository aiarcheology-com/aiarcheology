Test Focus: Sign-In & Account Access
Build: TBD

This build adds account sign-in. You now need an account to use the app, and access is granted per user during the beta.

Devices / Platforms
- iPhone (required)
- iPad (if available)

1. Sign In (Primary Focus)
- On launch you should see a sign-in screen
- Sign in any of these ways and confirm the app opens afterwards:
  * Email and password (create an account or sign in)
  * Continue with Apple
  * Continue with Google
  * Continue with Facebook — works only for our testers right now; if it's
    not enabled for your account yet, use email/Apple/Google instead
- If your account isn't enabled yet, you'll see an "Access pending" screen
  * Send us your email and we'll enable access, then relaunch

2. Account Management
- Open the drawer → Settings → Manage Account
- Try Change Password and confirm it works
- Confirm "Subscription" shows "Free Beta"

3. Sign Out
- Manage Account → Sign Out
  * You should return to the sign-in screen
  * You should NOT be able to use the app until you sign in again

4. Delete Account
- From "Access pending" or Manage Account, tap Delete Account
  * Use a throwaway account — this permanently deletes it
  * After deletion you should be back on the sign-in screen

5. Offline Behavior
- Turn off Wi-Fi/cellular and launch (or foreground) the app
  * You should see a "No connection" screen with a Try Again button
  * Reconnect, tap Try Again, and you should get back in

6. Core Regression
- After signing in, browse websites and confirm pages load normally
- Run object detection and verify annotations appear correctly
- Import a model from Files and verify it works

Beta note: the sign-in screen has a Development/Production switch so we can test either environment. Leave it on Development unless asked otherwise.

7. Report Issues
Please report any issues with:
  * What you were doing (steps to reproduce)
  * Device model and iOS version
  * Screenshot or screen recording if possible
