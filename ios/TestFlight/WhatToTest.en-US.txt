Test Focus: Model description now expands + Hessen Wind-Atlas demo link fixed
Build: TBD

What's new in this build — two small fixes:
1. In a model's annotation configuration, the model Description used to be cut off to one line;
   it can now be expanded to read the full text.
2. One of the example map links in the browser history (the Hessen wind map) pointed at a dead
   address that failed to load; it now points at the working Wind-Atlas Hessen map.

Reminder: you need an account to use the app, and (with payments on) an active subscription or
free trial to get past the paywall. TestFlight purchases use Apple's Sandbox — you are NOT charged
real money, and trial/renewal periods are accelerated.

Devices / Platforms
- iPhone (required)
- iPad (if available)

1. Model description expands (primary focus)
- Get past the paywall, then open a model's annotation configuration:
  drawer → the model list → tap a model to open its Configuration form.
- Look at the "Description" row. If the model has a long description it shows on one line first.
- Tap the Description row → the full description should expand and become fully readable,
  left-aligned and wrapping across multiple lines (no "copy" button on this row).
- The other rows (File, Type, Version, Author) should look unchanged. The "Link" row (when a
  model has a download URL) should still expand and still show its copy button as before.

2. Hessen Wind-Atlas demo link (primary focus)
- This only appears on a fresh install (or after clearing browsing history), where the app seeds
  a few example map links.
- Open the browser address/history (the location sheet) and find the Hessen wind map entry, or
  enter this URL directly:
  https://umweltdaten.hessen.de/mapapps/resources/apps/windatlas/index.html?lang=en
- Confirm the page loads and the Wind-Atlas Hessen map appears (it may take a moment to boot).
  Previously this link failed to load.

3. Light regression
- Browse a couple of normal websites and confirm pages still load.
- Run object detection and confirm annotations still appear.

Beta note: the sign-in screen has a Development/Production switch so we can test either
environment. Leave it on Development unless asked otherwise.
