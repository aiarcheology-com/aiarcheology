What's new in this build:
You now confirm what an imported model is. Each model's settings has a new Type control —
Detection, Classification, or Disabled — and after every import the app opens that control so you
confirm the type before the model can run (the app can't verify what a model actually does).
Models whose type the app couldn't read before (and which used to fail on import) now import too.
The model list also shows each model's type at a glance.

1. Import a model — you confirm its type
- Import a Core ML model (from Files or a URL). After it imports, an alert reminds you the app can't
  verify what a model does, then the model's settings open automatically so you confirm the Type
  (Detection / Classification / Disabled). The app pre-selects its best guess — confirm or change it,
  then tap Dismiss to accept.
- If the app couldn't work out the type at all, the settings open on Disabled with a red warning; the
  model won't run until you pick Detection or Classification.
- Change the type, close the settings, reopen it — your choice is still there. Force-quit and
  relaunch — still there.

2. Disabled = won't run until you choose
- Set a model's Type to Disabled. In the model list (left drawer) its on/off switch is greyed out —
  a Disabled model can't be turned on until you pick Detection or Classification.

3. Type shows in the list
- Each model in the left drawer shows its type (Detection / Classification / Disabled) under its name.

4. Switch type on a running model
- Enable a detection model and run it on a page. Open its settings and switch it to Classification.
  Detection should stop and the model should behave as the newly chosen type (no leftover boxes from
  the old type). Switching it to Disabled stops it entirely.

5. Report Issues
Please report any issues with:
  * What you were doing (steps to reproduce)
  * Device model and iOS version
  * Screenshot or screen recording if possible
