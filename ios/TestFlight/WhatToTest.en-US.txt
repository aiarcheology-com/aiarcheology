Test Focus: App startup & dependency wiring refactor (AIA-0385) — no visible change expected
Build: TBD

What's new in this build:
Internal restructuring only — how the app assembles its shared pieces at startup was consolidated
so there is a single clear owner ("composition root"). There is NO user-facing change. This build is
a regression check that sign-in, settings, downloads, and detection all behave exactly as before.

1. Launch & sign in
- Cold-launch the app. It should show the loading screen, then the sign-in gate, and let you sign in
  normally — no crash, no hang.

2. Settings — account rows
- Open the left drawer, then Settings. On a signed-in build, the account email and "Manage Account"
  rows should appear as before. Tap "Manage Account" — your profile should load.

3. Sign out
- Sign out (from Settings / Manage Account). You should drop straight back to the sign-in gate.

4. Downloads still complete in the background
- Start a model download, send the app to the background, then return — the download should finish
  and the model become usable.

5. Browsing & detection
- Browse a page and run a detection demo — bounding boxes / classification should appear and update
  as before. (Detection models now warm up at launch rather than when the browser first opens; this
  is invisible, but first detection may feel slightly quicker.)

6. Report Issues
Please report any issues with:
  * What you were doing (steps to reproduce)
  * Device model and iOS version
  * Screenshot or screen recording if possible
