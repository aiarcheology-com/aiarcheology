Please test:

2. Open the side menu → Models → the import screen. The model catalog option should be present as usual.
3. Open Settings → Account. The subscription row should read exactly as it did before.
4. Browse and run a detection to confirm nothing about the core flow changed.

Known limitations:

• None — this build contains no feature or UI changes.
