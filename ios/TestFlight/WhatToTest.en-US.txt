Test Focus: The application log that goes with a support report. Until now it recorded very little in TestFlight and App Store builds, and it was thrown away every time the app closed — so a report almost never described the problem it was about.

1. Open Settings > ML Browser. There is a new switch, "Keep a detailed log", and it is ON. Read the sentence under it and tell us if it is unclear.

2. Use the app normally for a few minutes — browse, run a detection, download a model. Then go to Settings > About > Contact support, turn on "Include application log", and tap Compose. Open the attached file in the mail draft. It should now contain a lot of detail, not a handful of lines. Nothing should freeze while the mail is prepared.

3. The important one: make the app record something, then FORCE-QUIT it (swipe it away), reopen it, and compose a support report. The log must still contain what happened before you quit. Previously it started from scratch every launch.

4. If you have a large log, the attachment arrives as a .zip instead of a .txt. Confirm it opens.

5. In the same support form there is a new row, "Save or share the log". Tap it and send the log to Files, AirDrop or a messaging app. Check the filename: it says "unredacted" only when you turned on "Send unredacted data". This is mainly for people whose device has no Mail account set up — that route could not attach anything before.

6. Turn "Keep a detailed log" OFF in Settings, then compose a report again. The attachment should be much shorter, and the app must not feel any different to use.

7. Clear your browsing history (Settings > ML Browser > History > Clear). This deletes the stored log too, on purpose — the log contains the addresses you visited.

8. "Restore Defaults" does NOT delete the log, also on purpose. It only resets settings.

9. Try a model download that fails — turn on Airplane Mode partway through a multi-file download. The log should name the file that failed and give a reason.

Please report your device model and iOS version with any problem, and attach the log if you can.
