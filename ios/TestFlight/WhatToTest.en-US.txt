Test Focus: Comparing several classification models side by side

What's new:

• With several classification models enabled at once, the label bubble now shows every model's results — each under its own header with the model's name and color dot. Previously only one model's labels were shown and the rest were silently dropped.
• Converted models continue to credit their original authors (previous build): imported .onnx models carry the original description, author and version.

Please test:

1. Enable ONE classification model and browse — the label bubble should look exactly as before (no header, top labels with percentages).
2. Enable TWO OR MORE classification models and browse an image-heavy page — the bubble should list each model separately: a small header with the model's name and a dot in its color, then that model's labels. Compare what each model thinks of the same page.
3. Check attribution: the dot color next to each model's name should match that model's annotation color (set in its configuration sheet) — labels must never appear under another model's name or color.
4. The pulsing frame flash should behave as before (it follows the first qualifying model's color and speed).
5. Detection models (bounding boxes) should be completely unchanged.

Known limitations:

• The frame flash is a single border, so with several qualifying models it shows the first one's color — per-model flash identity is the colored dot in the bubble.
