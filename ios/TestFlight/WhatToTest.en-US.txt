Test Focus: AppState internal restructuring (AIA-0390) — no visible change expected
Build: TBD

What's new in this build:
Internal restructuring only — the app's central state object was reorganized so each feature area
(detection, browser, account) is grouped into its own injectable, independently-testable unit, with
the central object reduced to a thin shell. There is NO user-facing change. This build is a
regression check that startup, sign-in, browsing, detection, downloads, and settings all behave
exactly as before.

1. Launch & sign in
- Cold-launch the app. Loading screen → sign-in gate → sign in normally. No crash, no hang.

2. Browsing & tab switching
- Browse pages; switch between the app's modes/tabs. Navigation and the tab bar behave as before.

3. Detection & labels
- Enable a model, run a detection demo — bounding boxes / classification labels appear and update
  as before. Start/stop detection behaves normally.

4. Downloads
- Download a model; background the app and return — the download still completes and the model
  becomes usable.

5. Settings & account
- Open Settings; the account rows (email, Manage Account) show on a signed-in build. Adjust a
  setting (e.g. brightness/contrast, show-labels) — it still takes effect.

6. Report Issues
Please report any issues with:
  * What you were doing (steps to reproduce)
  * Device model and iOS version
  * Screenshot or screen recording if possible
