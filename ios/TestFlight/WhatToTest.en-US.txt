Build: AIA-0761 (a shared link pointed at the wrong part of the page)

Test Focus: sharing a finding as a link, and what the person receiving it is told about where the
detection was. Nothing else changed, so if findings, saving, exporting or backing up misbehave,
that is worth reporting loudly.

- The link now points where the detection actually was. Find something with a model, save it, and
  before you save use the pinch/drag on the picture to crop in tight on the detection — that is the
  case that was broken. Now share that finding with the link switched on, and send it to yourself.
  Open the link. Under "Where on the page" you should see a small diagram of the page with the
  detection marked. It should sit where the thing was on the page as you saw it in the browser —
  for example, near the bottom-right corner if that is where it was. Before this build, that
  diagram described where the detection sat inside your crop, so a detection near the edge of the
  page was shown near the middle, and it was drawn far too large.

- Cropping harder should not move the mark. Save the same detection twice: once without touching
  the crop, once cropped in as far as it will go. Share both. The two links should put the mark in
  the same place and at the same size, because the detection did not move on the page — only your
  picture of it changed.

- Findings you saved before this build now say nothing rather than something wrong. Take any
  finding you already had on the device before installing this build and share it. Its link should
  show no "Where on the page" section at all. That is deliberate and is not a bug to report: the
  crop those older findings were saved with threw the original position away, so there is nothing
  truthful left to send. Everything else about the link — the title, the picture, the address, the
  QR code — should be exactly as before.

- Your existing findings must all still be there. This build changes how findings are stored, so
  please check this carefully after updating: open Findings and confirm every finding you had is
  still listed, with its picture, its title and its red detection box in the right place. If you
  can, update from the build you were already running rather than deleting the app first — a
  fresh install cannot test this at all.

- Back up and restore still round-trips. If you are signed in, back your findings up, then check
  they come back. If you use the export/import files instead, export a finding, import it back, and
  confirm the imported copy's link still marks the right spot on the page.
