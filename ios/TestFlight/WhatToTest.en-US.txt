Test Focus: Converted models now credit their original authors

What's new:

• When you import an .onnx model, the converted model now carries the original model's description, author, version and license from the source file — instead of showing the filename with everything else blank.

Please test:

1. Import Tiny YOLOv2: https://github.com/onnx/models/raw/main/validated/vision/object_detection_segmentation/tiny-yolov2/model/tinyyolov2-8.onnx — on the configuration screen, the description should read like "The Tiny YOLO network from the paper 'YOLO9000'…" and the author should be "Original paper: Joseph Redmon, Ali Farhadi" (previously both were the filename / blank).
2. Import an image classifier that carries no embedded metadata (e.g. ResNet-50 from the ONNX Model Zoo) — it should still import and classify exactly as before, with the filename as its name. Nothing should look broken or show empty "author"/"version" noise.
3. Re-import a model you imported before this build — its description/author should now be populated where the source file provides them.

Known limitations:

• The license is preserved inside the converted model and travels with an exported model, but is not yet shown on the configuration screen — that display is a separate change.
• Modern YOLO (v8/v11) detection is still landing incrementally; a YOLO11 export that uses unsupported operators may still fail to convert. Its attribution is read correctly regardless.
