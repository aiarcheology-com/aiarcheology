Test Focus: Model-management internals refactor (AIA-0388) — no visible change expected
Build: TBD

What's new in this build:
Internal restructuring only — the code that manages detection models (their settings, the running
detectors, and their downloaded files) was split into separate, testable pieces. There is NO
user-facing change. This build is a regression check that adding, enabling, disabling, and deleting
models still behaves exactly as before.

1. Add / import a model
- Add or import a detection/classification model. It should appear and become usable as before.

2. Enable / disable a model
- Toggle a model on, then off. Enabling should start detecting with it; disabling should stop it —
  no lag, no stuck state, no crash.

3. Delete a model
- Delete a model you added (not a bundled demo). It should disappear and its detector should stop.
  Deleting a model that came from a download should keep the downloaded copy available for re-import
  (its file must not be removed).

4. Reset all models
- Use reset / reset-all (if available). All added models should be removed and detection should stop
  cleanly, with no leftover detectors.

5. Detection still runs
- With a model enabled, run a detection demo — bounding boxes should appear and update as before.

6. Report Issues
Please report any issues with:
  * What you were doing (steps to reproduce)
  * Device model and iOS version
  * Screenshot or screen recording if possible
