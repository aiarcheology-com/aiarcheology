Build: AIA-0748 (sorting the findings list, and a tidier Findings toolbar)

Test Focus: the new sort control in Findings, and the new Data menu that now holds export and
import. Saving, sharing and backing up were not touched, so if those misbehave, report it loudly.

- The Findings toolbar changed shape. Open Findings. Where Export and Import used to sit as two
  separate buttons, there is now one button called Data holding both, and next to it a new
  up/down arrows button for sorting. Check the title at the top is not squashed or cut off — and
  please check this again with larger text turned on (Settings > Accessibility > Display & Text
  Size > Larger Text, pushed high). That is the case this change exists to fix.

- Export and import still work from their new home. Tap Data. Export a few findings, then import
  the file back. Both should behave exactly as they did before; only where you tap has changed.
  While an export or import is running, the Data button becomes a spinner and cannot be tapped —
  that is deliberate.

- Sorting by date, name and website. Tap the arrows button. You get three choices — Date,
  Alphabetical, Website — and a Reverse item. Date is the default and shows newest first, which is
  the order the list has always used. Alphabetical sorts by the title shown on each row. Website
  groups by the site the finding was captured on. Reverse flips whichever one you picked.

- Findings with nothing to sort by stay at the bottom — in both directions. This is the part most
  worth a careful look. A finding saved from a file rather than a web page has no website. Sort by
  Website: it should sit at the bottom. Now tap Reverse: it should STILL be at the bottom, not
  jump to the top. The same rule applies to a finding with no date, and to one with no title text.
  A row with no information should never lead the list, whichever way round you sort it.

- The choice is not remembered, on purpose. Pick Alphabetical, close Findings, open it again. It
  should be back to Date, newest first. That is intended for this build — tell us if you would
  rather it remembered.

- Two things that are expected, not bugs. If you switch order while scrolled down the list, you
  stay at the same scroll position and the rows move around you — so you may land somewhere
  unfamiliar; scroll up to get your bearings. And under Alphabetical or Website, a finding you
  save or sync while the list is open appears in its sorted place rather than at the top, so it
  may arrive off-screen. Judge whether either of these feels wrong in practice.

- Exported files follow the sort. Sort by Alphabetical, then export. The rows inside the exported
  file come out in that same order. Nothing depends on that order, so this is cosmetic — but it is
  a change from before, when the file was always newest-first.
