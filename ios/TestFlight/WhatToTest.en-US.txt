Test Focus: Download Reliability & Progress Tracking
Build: TBD

This build improves download reliability with better progress tracking, resume capability, and recovery after app termination.

Devices / Platforms
- iPhone (required)
- iPad (if available)

1. Download Progress Bar (Primary Focus)
- Go to Settings → Add Model → enter a URL for a large model
- Start downloading
  * The green progress bar should appear at the bottom of the list cell
  * Progress should update smoothly during download
- Pause the download
  * The progress bar should remain visible showing current progress
  * Status should change to "Paused"
- Leave the download list and return
  * The progress bar should still be visible with correct progress
- Resume the download
  * Download should continue from where it left off

2. Cancel Download
- Start a download
- Tap Cancel
  * Progress bar should disappear (reset to zero)
  * Status should change to "Cancelled"
- Restart the download
  * Should start from the beginning (not resume)

3. App Termination Recovery
- Start downloading a large model
- Force-quit the app (swipe up from app switcher)
- Reopen the app
  * If the download had resume data: status should be "Paused" (can continue)
  * If no resume data available: status should be "Failed" with message
  * Download should NOT be stuck in "Downloading" state with no activity

4. Background Download
- Start downloading a model
- Switch to another app or lock the device
- Wait for download to complete
  * Download should continue in background
  * Notification or completion status on return

5. Core Regression
- Browse websites and confirm web view loads normally
- Run object detection and verify annotations appear correctly
- Import a model from Files and verify it works
- Delete a model configuration and confirm it's removed cleanly

6. Report Issues
Please report any issues with:
  * What you were doing (steps to reproduce)
  * Device model and iOS version
  * Screenshot or screen recording if possible
