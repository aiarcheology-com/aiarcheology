Test Focus: Downloading models from the catalog on a real iPhone or iPad. This build fixes a fault that made multi-file model downloads fail on physical devices only — simulators and the Mac build were never affected, so please test on a real device.

1. Open the catalog and download a multi-file Core ML package, for example the YOLOv11 model "yolo11l-int8" from TheCluster/YOLOv11-CoreML. It should download and install without an error.

2. Check that the model then appears in your model list, select it, and run one detection with the camera or a photo. Downloading is only half the test — the model has to load and actually detect something.

3. Download an ONNX model from the catalog and repeat step 2. This uses a different internal path than a plain Core ML file, so please do not skip it.

4. Download a plain single-file .mlmodel and repeat step 2. This one worked before, so it is here to confirm nothing broke.

5. Download the same model a second time, and try cancelling a download partway through. Then check Settings for the app's storage size: repeated downloads and cancellations should not leave the app growing by leftover temporary files.

6. If a download does fail, note the exact message. Error text has changed in this build: you should see a plain sentence such as "Couldn't download this model." or "This model is too large to download." — not a raw code like "CatalogError error 6".

Please report the device model and iOS version with any failure, and include the application log if you can. A download that fails on a phone but works in the simulator is exactly the fault this build addresses.
